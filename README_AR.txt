NEXA | LUMA AESTHETIC & BEAUTY — FINAL SHOWCASE
================================================

طريقة الرفع على GitHub Pages:
1) فك ضغط الملف ZIP.
2) افتح مجلد NEXA_Final.
3) ارفع index.html ومجلد assets وملف README_AR.txt إلى جذر مستودع GitHub نفسه.
4) من Settings > Pages اختر Deploy from a branch.
5) اختر main ثم /(root) ثم Save.
6) انتظر اكتمال النشر وافتح رابط GitHub Pages.

مهم: لا ترفع ملف ZIP وحده ولا تفصل مجلد assets عن index.html.

تخصيص نسخة كل عميل:
- افتح index.html.
- ابحث عن NEXA_CONFIG في نهاية الملف.
- عدّل clinicName وcity وwhatsapp.
- عدّل اسم العيادة في عناصر HTML، الخدمات والأسعار وساعات العمل والعنوان.
- استبدل الصور داخل assets مع الحفاظ على أسماء الملفات، أو حدّث مسارات الصور في HTML.

وظائف النموذج:
- تصفية الخدمات حسب التصنيف.
- فتح تفاصيل كل خدمة في نافذة منبثقة.
- نموذج طلب موعد مع تحقق أساسي من الحقول.
- عند إضافة رقم واتساب بصيغة دولية من دون + أو مسافات إلى NEXA_CONFIG.whatsapp، يفتح رابط رسالة واتساب مُعدّة مسبقاً.
- لا يوجد حالياً اتصال بقاعدة بيانات أو تحقق آلي من توافر المواعيد؛ إرسال النموذج هو طلب تواصل وليس تأكيد حجز.

الصور والأسعار وبيانات لُمى توضيحية لغرض العرض فقط. يجب استبدالها بمواد معتمدة من كل عيادة قبل النشر التجاري. لا تستخدم صور أشخاص أو نتائج قبل/بعد دون موافقة وحقوق استخدام مناسبة.

ملاحظة تقنية: الخطوط تُحمّل من Google Fonts عند توفر اتصال إنترنت، مع وجود خطوط بديلة محلية.
